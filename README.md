## 0. 프로젝트 개요
 
- **미션명**: 내 컴퓨터에 개발자용 '작업실' 꾸미기
- **목표**: 터미널(리눅스 CLI), Docker, Git/GitHub를 직접 세팅하고, 실행 결과(로그/접속/데이터 유지)로 검증한다.
- **핵심 학습 내용**
  - 터미널로 디렉토리/파일/권한 다루기
  - Docker 설치·점검, 컨테이너 실행/관리
  - Dockerfile 기반 커스텀 이미지 + 포트 매핑
  - 바인드 마운트 / 볼륨으로 변경 반영과 데이터 영속성 확인
  - Git 설정 및 GitHub 연동
